# Yau Le Qi (饶乐祺) | Portfolio

Personal website and portfolio of [Yau Le Qi](https://leqi.dev).

Incoming Computer Science student at Hughes Hall, University of Cambridge. Built with React, Tailwind CSS, and Vite. Deployed on Cloudflare Pages.

## Tech Stack
- Frontend: React.js, TypeScript
- Styling: Tailwind CSS
- Animation: Motion (framer-motion)
- Build Tool: Vite
- Deployment: Cloudflare Pages

## Development

```bash
# Install dependencies
npm install

# Start the dev server
npm run dev

# Build for production
npm run build
```
